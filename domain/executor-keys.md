# Ключі виконавців: довідка вендорів

Розділ кожного вендора — довідка поруч із формою на сторінці «Стан і налаштування»: `domain/tools/gen.mjs` бере
розділи ``### … (`ключ`)`` і вбудовує їх у `core/executors/gen/providers.json` (поле `help` пресету з
`domain/providers.yaml`). Тому кожен розділ самодостатній. Ключ підключають на тій самій сторінці: «Виконавці» → «Додати»; клас даних
виконавця визначає, які проєкти він бачить.

### OpenRouter (`openrouter`) — роутинг на сотні моделей
1. openrouter.ai → Sign in (Google або GitHub).
2. **Settings → Privacy**: вимкнути дозвіл маршрутизувати до провайдерів, що логують або навчаються на запитах —
   окремо для платних і безкоштовних моделей. Без цього частина `:free` моделей вчиться на ваших даних.
3. **Keys → Create key**: назва `litopys`, ліміт кредитів за бажанням.
4. Безкоштовно: моделі з суфіксом `:free`, ~20 запитів/хв і ~50 на день (невдалі виклики теж рахуються). Після
   поповнення на $10 — ~1000 на день.
5. Клас за пресетом: `public`; `internal` — лише з вимкненим навчанням у п.2.

### Groq (`groq`)
1. console.groq.com → вхід.
2. **API Keys → Create API Key**.
3. За бажанням: Settings → Data Controls → нульове зберігання (ZDR).
4. Безкоштовно (план Developer): напр. `openai/gpt-oss-120b` — 30 запитів/хв, 1000 на день, 8 тис. токенів/хв.
5. Клас за пресетом: `internal` (не зберігає й не навчає за замовчуванням).

### Google AI Studio — Gemini (`gemini`)
1. aistudio.google.com → вхід Google-акаунтом.
2. **Get API key → Create API key** (створює або обирає проєкт Google Cloud).
3. Безкоштовно: найщедріший тариф; ліміти — у AI Studio на сторінці лімітів проєкту.
4. **Безкоштовний тариф вчиться на запитах і відповідях, їх можуть читати люди-рецензенти.** Для України (поза ЄЕЗ)
   це діє. Без навчання — лише з увімкненою оплатою.
5. Клас за пресетом: `public`.

### Mistral (`mistral`)
1. console.mistral.ai → вхід.
2. **Billing/Plans → Experiment** (безкоштовний, потрібне підтвердження телефону).
3. **API Keys → Create new key**.
4. Безкоштовно: квота плану Experiment, ліміти залежать від акаунта.
5. Умови навчання для безкоштовного плану першоджерелом не підтверджено — клас за пресетом `public`.

### NVIDIA NIM (`nvidia`)
1. build.nvidia.com → вхід (NVIDIA Developer).
2. Відкрити будь-яку модель → **Get API Key**.
3. Безкоштовно: 120+ відкритих моделей, ~40 запитів/хв; умови — лише для розробки й тестування.
4. Клас за пресетом: `public`.

### Cloudflare Workers AI (`cloudflare`)
1. dash.cloudflare.com → вхід.
2. **AI → Workers AI → Use REST API → Create a Workers AI API Token**.
3. Там же скопіювати **Account ID** — він потрібен разом із ключем (поле `account_id` у формі).
4. Безкоштовно: 10 000 «нейронів» на день.
5. Клас за пресетом: `public`, доки умови не перевірено.

### Cerebras (`cerebras`)
1. cloud.cerebras.ai → вхід.
2. **API Keys → Generate API Key**.
3. Безкоштовний тариф на дату статусу не підтверджено — перевіряється при підключенні.
4. Клас за пресетом: `public`, доки умови не перевірено.

### Ollama (`ollama`) — локально
Ключ не потрібен, лише адреса (напр. `http://<хост>:11434/v1`). Клас за пресетом: `local`.

### Платні: OpenAI (`openai`), Anthropic (`anthropic`)
platform.openai.com → API keys; console.anthropic.com → API Keys. Лише API-ключ, ніколи не підписка: умови підписок не дозволяють автоматичних викликів.
Клас за пресетом: `internal`.
